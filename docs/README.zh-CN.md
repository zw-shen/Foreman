# Foreman

> 更好地管理你的大模型，而不是盲目听信它们。

Foreman 是一个 git-backed 的 AI coding agent 监工看板。它不相信 agent 自己说"完成了"，而是直接检查任务 repo 里真实发生的 commit，核实约定好的完成/失败信号，并且要求每次任务在 agent 之间交接时都留下结构化的交接文档（而不是流水账）。

[English](../README.md)

## 状态

目前处于早期设计阶段，尚无具体实现。

## 核心思路

- 每个任务对应一个 git repo（有一个默认 repo，即使多个 agent 参与同一个任务，也只看最终结果）。
- 每次指令完成都要在 commit 级别核实，而不是听 agent 自己汇报。
- 每个任务包含：项目背景、当前目标、当前进度、TODO/DONE 清单、能做什么/不能做什么、结构化交接文档。
- 交接文档有模板约束，防止写成流水账——重点记录卡在哪、已经尝试过什么方案、接下来该做什么。
