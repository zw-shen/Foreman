# Foreman

> 更好地管理你的大模型，而不是盲目听信它们。

Foreman 是一个 git-backed 的 AI coding agent 监工看板。它不相信 agent 自己说"完成了"，
而是去看它在一个共享的 **context repo** 里究竟留下了什么：真实的 commit、约定格式的状态文件、
以及一份结构化的交接文档（而不是流水账）。

## 状态

早期阶段，但已经可以跑。Node.js，**零 npm 依赖**，无数据库，无构建步骤。

    npm start        # http://127.0.0.1:4600

**无鉴权**，默认只监听 localhost，不要暴露到网络。

完整设计见[产品与功能定义](PRODUCT.zh-CN.md)。

## 核心思路

- **Foreman 不是 AI。** 它不调用模型、不读你的代码、不分析 diff。
  它是一个对 agent 产出做反应的程序。
- 它只盯**一个仓库**：context repo，所有任务共用。里面放通用知识、项目知识，以及每个任务一个目录。
- agent 把自己的状态、TODO、交接文档写到该仓库的约定路径，
  Foreman 读取它们，并用仓库真实的 git 历史对照这些声明。
- **声称完成却零提交**的任务会被标成「存疑」—— 板子上这一格就是整个工具存在的理由。
- 因为 Foreman 看不到代码，agent 必须**用文字说清改动**：每个文件改了什么、为什么、影响什么。
  更详细的改动明细按需索取 —— 你发起，Foreman 生成一段追加提示词，agent 写下来，Foreman 渲染。
- 交接文档有模板约束并且会被校验，防止退化成流水账。
